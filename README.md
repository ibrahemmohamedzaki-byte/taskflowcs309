# taskflowcs309
TaskFlow: a full-stack to-do list web app built with the MERN stack (MongoDB, Express, React, Node.js). CS 309 team project.

## What TaskFlow does

- **Accounts:** register and log in. Every user sees only their own tasks.
- **Task management:** add, edit and delete tasks, and mark them as done.
- **Organization:** give each task a priority, a category and a due date.
- **Search and filters:** find tasks by text, status, priority or category.
- **Profile:** edit your name and see your progress (total, completed, active and overdue tasks).
